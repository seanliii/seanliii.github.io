02 小游戏 · 3 个

2D 游戏很方便，3D 建构仍然困难。

一个对话框就能完成玩法设计、美术素材生成与最终可玩的游戏；3D 场景会出现穿模、混乱，调试成本明显更高。

锈湖风格2D 可玩

单机解密小游戏

参考锈湖风格，在房间内找线索、解谜，模型自行设计故事、生成美术素材并拼贴进游戏框架。

提示词

请帮我做一个解密小游戏，这个游戏为单机解密风格，设计和玩法可以参照锈湖（附件图片），用户需要在房间内找线索，然后进行解密。你可以设计一个完整的故事，引导用户解密。自行校准各个按键的位置，不要错位，同时相关物品可以参考真实物品进行设计，可以自行搜索一些素材，尽量环境逼真一些。请基于这个游戏目前的框架，并以游戏美术总监的角色，为这个游戏列全美术清单，按优先级分组，每项写清楚：用途、尺寸、数量、风格锚点，并附一条可直接投喂生图的完整提示词，并调用生图工具，完成游戏美术素材设计，符合该游戏风格。把制作好的素材，拼贴到原有的游戏框架中，让游戏画面整体看起来精美、流畅、符合氛围。请完成基础检查，确定美术素材没有错位、或者有其他 bug，有问题的话就自行修复，然后给我一个最终版可玩的游戏。

3D 尝试仍在打磨

跑酷接入 Blender

三跑道、铁轨形态、火车头、高低栏杆与金币；人物与火车头参考原图做 3D 建模。画面可跑，但仍有穿模与质感问题。

提示词

我希望做一款跑酷小游戏，参考附件截图，三根跑道，人物可以在三根跑道内切换，跑道可以模拟铁轨形态，障碍物有火车头（人物可以通过跳跃跳上火车头），栏杆（高栏杆可以从下面滑过去，低栏杆只能从上面跳过去），同时跑道上可以有金币，人物经过就能获取金币，人物建模和火车头参考我给的图片，进行 3D 建模，需要画面流畅自然。

结论 做得好的，与还没做好的

已经比较稳的

  • 2D 交互网页大部分能复刻，版式、按键、页面切换基本可控。
  • 2D 游戏：一个对话框完成玩法、素材生成与可玩产出，多模态协作顺畅。
  • 生图速度快、成功率相对高，可控性比通用聊天产品更强。
  • 参考截图能理解基本玩法；同等条件下，竞品只给截图容易出现乱码。

还需要继续打磨

  • 3D 与空间类网页困难，复杂结构会出现穿模、布局混乱。
  • 3D 建模大多只能做简单多边形，曲线建模效果不好，调试成本高。
  • 视频类：白模构建弱、直接视频生成弱、复杂特效剪辑难；大文件口播工程不好做。
  • 整体仍偏慢、失败率不低，长难任务存在未完成就交付。
  • 同提示词能否稳定复现、强制调用工具是否一定成功，仍需验证。

读这些案例时请注意

  • 效果受提示词与制作流程影响很大；简单提示词不能稳定做出高精度成果，需要反复测。
  • 视频是真实产物录屏，但不等于同提示词每次都能复现同样效果。
  • 3D 与视频案例保留在这里，是为了说明当前边界，不作为“已经稳定”的证据。
