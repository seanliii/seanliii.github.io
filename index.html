🧩 工作原理

1

写入记忆

任意 Agent 调用 memory.set(key, value)，写入共享池

2

广播同步

MemOS 服务通过 WebSocket 向所有注册 Agent 推送变更

3

跨设备读取

不同机器上的 Agent 读取时获得完全一致的记忆状态

4

隔离模式

MULTI_AGENT_MODE 下，不同 agentId 数据隔离，互不干扰

📦 快速接入（3分钟跑通）

# 1. 安装 Cloud Plugin（OpenClaw 内执行）
# openclaw skill install memos-cloud

# 2. 配置环境变量（~/.openclaw/openclaw.json 或 .env）
MEMOS_API_URL=https://your-memos-server.com
MEMOS_TOKEN=your_token_here
MEMOS_USER_ID=shared_pool_user
MEMOS_MULTI_AGENT_MODE=true

# 3. 在任意 Agent 中写入记忆
# 小蓝虾（设备A）写入：
memory.set("last_stock_scan", { ticker: "NVDA", signal: "buy", ts: 1716300000 })

# 小红虾（设备B）读取：
memory.get("last_stock_scan")
# → { ticker: "NVDA", signal: "buy", ts: 1716300000 }
