# 鹈鹕骑自行车 · Pelican Coast Ride

一个**全程序化生成**的 Three.js 3D 网页游戏：戴头盔墨镜、系红围巾的鹈鹕，
在黄昏的海岸公路上骑自行车抓鱼，一路骑进星光月夜。

## 在线玩

打开 `dist/index.html` 即可（单文件、零外部依赖、零外部素材，
模型/纹理/动画/音效全部由代码实时生成）。

## 玩法

| 按键 | 动作 |
| --- | --- |
| W / ↑ | 加速 |
| S / ↓ | 刹车 |
| A / D | 左右变道（路过跳鱼时保持同侧即可抓到） |
| 空格 | 跳跃 |
| T | 抬头展翅炫技 |
| B | 车铃 |
| C | 切换镜头（尾随 / 侧面跟拍 / 电影运镜 / 鹈鹕视角） |
| M | 静音 |
| H | 帮助 |
| P / Esc | 暂停 |

不操作 20 秒进入**自动驾驶**（鹈鹕自己巡航抓鱼，镜头切电影模式）。

支持触屏：移动端自动出现虚拟按键（方向 / 跳 / 铃 / 镜头 / 炫技）。

## 特性清单

- **鹈鹕**：程序化建模（头盔/墨镜/长喙/喉囊/翅膀/尾羽），双腿 IK 实时踩踏板，
  身体随踩踏起伏，头部随机张望、偶尔回头看镜头，抓鱼时喉囊鼓动，
  红围巾为 **verlet 布料模拟**（风力∝车速、重力、躯干碰撞、约束求解）
- **自行车**：轮胎/轮圈/辐条/车架/前叉/车把/座垫/链条/牙盘/曲柄/脚踏/车筐/车铃，
  轮速、曲柄与车速、踩踏严格同步
- **世界**：无限海岸公路（正弦弯道 + 路段回收），程序化海洋着色器
  （顶点波浪 + 菲涅尔天空反射 + 太阳镜面闪光），沙滩/礁石/护栏/路灯/棕榈/草丛/路牌
- **昼夜循环**：360 秒一昼夜，从黄昏出发 → 星空月夜 → 黎明 → 白天；
  天空穹顶着色器（渐变 + 太阳 + 闪烁星星），路灯天黑自动点亮，萤火虫、月光
- **镜头**：4 种（尾随/侧面/电影/POV），过弯侧移、高速 FOV 扩展与微震
- **音频**：WebAudio 实时合成——风声(随速)、海浪、踩踏驱动的芯片音乐
  （16 步音序器，节奏=踏频）、车铃、抓鱼、跳跃、落地、炫技、成就、海鸥
- **玩法**：跳鱼抓捕、15 个成就、最佳里程 localStorage
- **性能**：实例化与对象池、单方向光紧凑阴影、FPS 自适应画质（高/中/低）、
  页面隐藏自动暂停、尊重 `prefers-reduced-motion`

## 构建

```
python3.12 build.py   # 把 vendor/three.min.js 与 src/game.js 内联进模板 → dist/index.html
```
