# 2024年1-7月个人总结

**项目一、【多米诺】对话效果提升**

**1.成果：**负责主对话模型体验，0-1搭建主对话模型全流程迭代。包括：

1）定义北极星指标：首聊十轮率、留存

2）分析对话体验：长留与流失用户及对话分析

3）丰富对话场景：角色/IP扮演、电话、话题交流、真人陪伴

4）提供优质数据构建：建立优质数据标准、提供&处理和改写优质对话数据（快点&话本小说、星&筑、pia戏、音声、cai、系统文、网文、音声台本、播客等）、线上优质数据回流、最终打通算法、产品、标注三方建立优质数据飞轮

5）对齐体验标准：通过sft、dpo等手段优化长轮次遵循、剧情表现、负向case、色情等

6）模型能力提升：agent自我进化、识别user行为画像、IP类角色RAG、多模态交互（场景识别、生图发图、理解图），复杂指令遵循推理架构（发图时机推理、触发记忆、触发剧情推动）

7）模型灰度实验：模型评估、实验灰度、线上分析等

**2.指标：**

1）整体留存表现：6月末相比3月初，整体日活次留28.6%提升到50.3%，7留17.9%提升到31.4%，30留10%提升到22.4%，新用户次留19%提升到33.1%，7留6.2%提升到9.7%，30留2.8%提升到5.2%；7月末整体用户次留56.3%,7留37.2%，新用户次留37.5%，7留11.8%。

2）整体对话表现：日活用户平均APP时长从20分钟涨到46.8分钟，人均对话agent从4.6涨到6.3个，聊天用户占比从54%涨到86%，人均聊天轮次从149.7涨到398.2

3）模型实验中显著数据：融合模型v0.2在5.15上线为主模型，相比minimax 5.5s整体日活次留提升5.5pp，相比星野5月模型minimax 6.5t pro，longcat主模型对新用户单agent轮次提升30%；

**项目二、【角色工厂】角色供给&分发**

**1.成果：**负责整体角色供给，0-1构建优质角色自动化生产管线，包括：

1）人设：角色人设自研模型、角色挑优模型，角色打标模型

2）声音：声音模型优化，声音整体能力建设

3）图像：重新搭建优质角色图模型（指令泛化模型、基座、lora、模版训练平台）

4）品类：IP、陪伴、多样性

5）分发：标签体系、首页推荐策略、频道分发、主动消息推荐、审核

**2.指标：**通过OGC和UGC提升优质供给及站内留存，核心品类有陪伴类、IP类、多样性角色

**1）陪伴角色：**

a）对话效果：角色工厂和以往官方创建相比，单Agent对话平均轮提高107.93%，和用户创建相比提高27.29%。

b) 优质生产效率：通过迭代角色自研模型和搭建管线，6月1pd可上线50个新角色，比过去人工1pd上线3-5个，人效提高10-20倍左右，9月可达100个角色1pd，整体头部率提高9.1pp、整体腰部率提高51.88pp；和用户创建相比，整体头部率提高4.05pp、整体腰部率提高11.86pp。最终该生产模型嵌入创建工具给用户提升UGC供给质量。

**2)IP角色：**

a）对话效果：新创建原神角色对比WOW已有原神角色，Agent 访问次日留存提升71.10% (12.87% -> 22.02%)，Agent访问次3日留存 50.41% (7.34% -> 11.04%)；对比WOW头部表现5%角色访问次留提升 57.29% (14% -> 22.02%)，后续采用RAG批量化管线优化影视小说、游戏动漫IP效果。

b）优质生产效率：搭建IP类角色批量化生产管线及标准，目标从当前1pd约3个提升到20个，后续给UGC提供此类工具

**3)多样性角色**：

a）留存提升：多样性角色及首页推荐新策略效果， 新用户次留涨2.5pp

b）新增品类：泛知识（书籍、话题）、文字游戏（系统文、互动小说）、社交工具、真人博主

**项目三、【内容工厂】内容供给&分发**

**1.成果：**负责角色的内容供给，0-1搭建优质内容生产管线，包括日记页，角色相册，互动小说，私密日记等

1）图文管线：搭建角色人设-对话记录-文字模型-图像模型-人工挑优-线上推荐的工作流，基于角色与用户对话生产内容，搭建微小说、漫画、日记、朋友圈、直播FM、语音房等角色内容管线

2）话题聊天模型：支持对外部内容和角色内容聊天，在陪伴和剧情扮演外，引入优质内容作为新话题

3）互动小说：优化供给标准及新互动小说模型迭代

**2.指标：**通过新内容品类引入新对话场景，促进用户留存提升

1）日记页：引入日记页内容，全量新用户次留提升1.5pp；优化供给质量和分发且加入促活策略，日记页功能次留20%涨到34%，人均发起聊天item从0.17涨到0.32，十轮率48.44%涨到52.32.3%，展点4.7%涨到8.3%，，人均轮数47到59。

2）互动小说：新上线模型+新供给，互动小说访问次留8%提升到11%；用户平均每bot停留时长50提升到80s；用户每bot平均轮次从4.5轮提升到12轮。
