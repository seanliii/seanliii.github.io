# 8.29-9.7

## 总目标

**一句话：**军团从"能跑"走向"能打"——用户一句话指挥，军团把活真正干完、把真东西（Excel / 网页 / 代码文件夹 / 视频）交到手上；并且用同题对打证明不输世界顶尖，没证明之前不自封第一。

**产品长什么样：**34 个成员 = 27 家答题军团（全部真跑验证真交付）+ 5 个能力后端（浏览器/桌面控制）+ 2 个协作平台；配 2681 件共享工具、Docker 云真机（网页直控 Android/桌面）、75 个搜索引擎。用户发一句话，系统自动分诊：简单题几秒直答，真项目自动选 3-5 个成员并行或流水线，失败自动换人补位，最后交付真实文件。

**本周节奏（三个阶段）：**先把家底盘清楚（8.29-8.30 复检+纠偏+首脑定型）→ 再让全员能打、用户等得少（8.31-9.2 速度根治+前端重造）→ 最后跟世界顶尖同题对打（9.3 终极大考+云真机+Teamwork 对标）。

## 军团介绍与理念

**军团是什么：**不是聊天机器人，是"AI 劳动军团"——用户一句话指挥，军团把活真正干完，把真东西（Excel / 网页 / 代码文件夹 / 视频 / PDF）交到手上。聊天只是入口，交付才是产品。

**一句话发过去会发生什么：**系统先自动分诊——简单问题几秒直答不铺开；真项目自动启动参谋部，选 3-5 个成员并行或流水线干活；单家失败自动换模型自救，彻底失败跨家接力（原任务+错误+文件+工作目录整体移交）；缺软件自己装、缺账号暂停成待办等用户处理；最后真执行、真交付、真文件。

### 六台咬合的机器

- **人才系统**：34 个成员 = 27 家答题军团（21/21 全量真跑验证全部真交付）+ 5 个能力后端（浏览器/桌面控制）+ 2 个协作平台；内置 10 家深度适配，外部 24 家一条命令接入。不赌任何单家——deepseek 出 884 字专家级、cc 出 189 字极简，并行让最优结果自己浮现。
- **军械库**：2681 件共享工具 + Docker 云真机（noVNC 网页直控 Android/桌面 + 反爬隐形浏览器栈）+ 75 个搜索引擎四体系；缺工具自己上 GitHub 搜、装、验。
- **自愈免疫系统**：56 组"专家×模型"已知坏组合开跑前直接避开；错误分诊分"药不行"（换模型）与"路不通"（换人/修环境）；双层自愈状态机 run→diagnose→self_repair→handoff→替补→交付。
- **进化飞轮**：成功交付进经验库、场景战绩账本、Wilson 置信度自动升降级模型、踩过的坑固化成守卫测试；Skill 工厂支持跨用户进化（A 装的 B 立即可见但互相隔离）。
- **血脉（教师池）**：12+ 家全球最强 harness 完整源码在仓库（codex / Claude Code / DeepSeek / Hermes / Penguin…），任何成员可以读同伴源码、工具、trace 学艺——按真实历史效果动态选老师，不看固定排行榜。
- **三条业务线共生**：AI 军团主引擎 + E2B 云沙箱（8 个社区运营马甲）+ 数据仓库（30 类行为事件宽表），互相喂血。

### 理念

- **群体 > 个体，但必须证明**：核心命题是"一群普通 agent 咬合好，能不能打赢一个顶尖 agent"。盲评 85.8 > 84.9 首次成立，但同题对打的大规模证据还是 0%——没证明之前，不许自封第一。
- **诚实文化**：主动纠正历史夸大口径（"14 家同质 harness"实为 10 家可派 + 4 类后端；"1950 件工具"实为结构验证非逐件真跑）；任务全失败时诚实返回未交付，不装成功；假文件过不了关（查 magic bytes/文件头/SHA-256）。
- **人是边界**：危险动作（支付、删数据、公开发布、真实凭证）必须暂停等用户确认；验证码/支付/风控须用户本人处理；用户确认后断点续跑。
- **一切要有证据**：交付要有文件、测试要有账本、性能要有前后对比数字、结论要有盲评；统一验收中心 + 发布门（质量分 ≥80 才可发布）。

### 模块二：首脑与编排（谁来指挥）

**目标：**解决三个问题：谁来当首脑、首脑怎么干活、首脑挂了怎么办。之前的隐患：规划首脑写死是 Kimi 模型、复杂任务里 captain 只催不取消、UI 子任务递归派生卡死。

#### 过程

- **动态竞选真跑**：Auto/CC/Codex 三家真实参选、各自提交编排方案、按可执行编排完整度选出 Auto 当选（captain=auto 带 bids/tasks/hierarchy）。真跑还揭出 CC 竞选 JSON 被截断误记为 unwilling 的协议问题，改成了结构化输出。
- **换届 E2E**：Codex 首脑创建 handoff-context.md → 结构化 handoff_captain → CC 接任并读取前任完整现场 → 交付 handoff-final.md，全程 30.18 秒，delivered 2/2。
- **默认首脑定型**：同题实测三家领队——autoloop 128 秒不收敛无交付、meyo-captain 并行派 2 家完成源码级综合、Polly 恢复力好但突破不了成员上限。最终定：Omnigent 当编排运行时（原生支持并行派活、"项目经理操作系统"）+ Meyo Supervisor 当事实源 + autoloop 当逃生舱 + Polly 当大工程模板；11/11 项检查唯一全过。
- **确定性监督器（双保险）**：光靠模型自觉不行。DeterministicSupervisor 做活动时间监控、预算超时自动停、健康替补、证据 handoff、交付门。真验证：2 秒预算自动取消换人，45 秒预算的正常任务 12.7 秒完成不误杀，回归 39 passed + 浏览器 46/46。
- **双层自愈状态机**：run→diagnose→self_repair→（失败才）cancel→handoff→替补自愈→delivery，每步结构化事件即时写 Cloud RunStore，输出 autonomy/context_integrity/flow_integrity 三评分。专项 8/8、Supervisor+Cloud 29/29。
- **首脑作战上下文**：CaptainContext 让首脑开任务自动带齐目标/验收/记忆/成员健康/源码地图/工具摘要/预算/交付合同，不再从零开始；OmnigentRuntimeManager 自动启停 server、失败自动 fallback autoloop，用户零运维。
- **Auto 产品模式修复**：删掉 finalize_answer/评分流水线等 benchmark 残留，"不需要联网"时分诊不暴露网络工具，从 125-170 秒反复搜索降到 33.2 秒首轮成功。

#### 结果

- 首脑竞选、换届、监督、自愈、作战上下文全部真跑通过，专项回归全绿（35/35、8/8、29/29、46/46）。
- 复杂任务闭环失败根因（UI child 递归 fork 卡死、captain 只催不取消、产物缺失）全部修复，配了 investigate/fanout/synthesis-delivery 三套首脑 Skill。

### 模块三：速度（用户等得少）

**目标：**一句话提问原来要等 67 秒，并发多家会互相拖到超时——目标是让用户"没有卡死感"：简单题 10 秒内、并发不互相拖累、等待时有反馈。

#### 过程

- **67 秒真凶链拆解**：规划器占 30s（kimi 生成结构化 JSON 慢）→ 换 gpt-5.4 裸调降到 2.8s；简单题不走 solo → 加 solo 快路径。67s→18s→9.1s（commit 3045f10e）。
- **协议瘦身 AB 实验**：真根因是每单注入 LEGION_PROTOCOL 9643 字 + prelude 5000 字 ≈1.4 万字拖慢推理。8 个变体 AB 测三个维度，最优 I_layered 2987 字（qa 5.0s）、I2 1155 字（qa 3.7s）；**所有精简变体在需要工具的任务里都真调了工具，能力零损失**。context 省 42%（commits 1a282acf/c199d263）。
- **并发根治**：6 家并发 60s 全 TIMEOUT，用 py-spy profile 揪出元凶是 singleflight 锁，修复后 6 家并发 14s 完成（e8d16fda/3f5ad5a8）。
- **进程内直调**：core 家跳过子进程——codex 19→8.6s（首）/7.2s（热）、hermes 13.4→6.1s、cc 15→9.2s（5340e3bc）；external 家跳隔离子进程 20s→4-6s（f9c6fd46）；子进程超时/退出 0 孤儿三层根治（f282c14d 等）。
- **派活前置**：探活 8.8s 加 TTL 缓存+预热 → 毫秒级；server 家进入 10.25s→2.23s（159a1308）。
- **codex 反复 rc1 根因**：bridge 进程继承死代理连不上内网网关，修一行传 NO_PROXY → 17.9s 真交付（731f0ce8）。
- **其他**：_build_prelude 5.58s→0.09s；工具箱冷启动 14s→0.11s；appid 新模型零改代码自动适配（实测 14→15 模型）；规划器按任务性质判 scene（写代码→sol、解释杠杆→deepseek-v4-flash 便宜款、英译中→GLM-5.3）。

### 模块四：前端与用户体验

**目标：**前端不是套皮，是让普通用户"看得懂、用爽、拿到结果"的产品出口。上周自评设计完整度只有 5/10（审批按钮是假动作、三套 HTML 只有配色差）。

#### 过程

- **第一场仗：自曝家丑**——派 5 个军团成员当首脑各自组队审自家前端，暴露：审批 UI 是假动作（P0）、三套 HTML diff 实测仅 14 行（只是配色差）、长期任务模型太浅、工具/Skill 无归因展示。

- **第三场仗：体验重造**——对话流原生化 6 项（智能滚动+回到最新浮标、过程流执行详细/完成折叠里程碑、补位接力可感演出 ⚠️遇阻→🤝接手、audio 播放器）；三执行模式现场化（⚔️PK 并行 tab / 🔗接力卡 / 👑首脑竞选）；首页能力墙 10 卡+灵感墙；交付物渲染支持图/视频/audio/表格/PDF/代码文件夹/下载。
- **订阅面板重做**：历史订阅跨会话聚合、点击跳回所属对话、区分"现在检查一次/变化后自动生成/固定时间执行"；新增 GET /api/legion/crawl/history；用户隔离验证（Alice 看不到 Bob 的私有订阅）。
- **三套真信息架构**：💬专注对话（单列）/ 📋任务工作台（两栏）/ 🎛️指挥中心（三栏），真布局差异非配色，带 mode_reason 合时机提示。
- **bug 硬仗**：100 测试方向 /loop 全部完成，修 7 个真 bug——4 处并发丢更新（无锁 load→save，实测 10 并发写入剩 3 条；7d071f88+5f73a97a）、model_pref 不校验 harness、skill install 空 source 挂 20s、inspire n≤0 返空、新对话首页能力墙消失。9.1 再集中修约 13 个：慢端点（capabilities 35s、安装中心 API 13.8s→3.7ms、探活缓存 35s→94ms）、首脑偏好静默失效、工具箱搜索假动作、审批 decide 状态码语义、云真机 exec 路径、交付物 404、penguin 空转。
- **根因修复**：空军团卡重复展示根因是 resumeLiveV2() 每 1.5s 轮询不断生成空卡——改成同一 team_id 复用同一张卡；penguin 空转真根因是拿长度当交付判据（len<40 把"好"误判未交付），修成过滤待命语后为空才算没交付。

## 护城河（综合本周内容）

**护城河的本质：**单点功能都能被抄，抄不走的是"六台机器的咬合"和"越用越强的飞轮"。本周每一项工作，最后都沉淀成下面八层壁垒的一层。

### 第一层：成员规模与多样性

21/21 家全部真交付、34 成员、外部 24 家一条命令接入——没有第二家把这么多异构 agent 真跑通在一个军团里。多样性本身就是生产力：同题实测 deepseek 出 884 字专家级、cc 出 189 字极简，用户不赌单家，并行让最优浮现。这周还摸清了每家的速度底牌（快档 3.6-8.3s、核心家 7-14s）和模型偏好（hermes→kimi-k3、cc/jcode→gpt-5.6-sol），派单从此有据可依。

### 第二层：速度体验

一句话简单题 67s→9.1s、6 家并发 60s 超时→14s、codex 进程内直调 7.2s、协议 context 省 42% 且能力零损失（8 变体 AB 验证）。速度不是玄学优化，是每个数字背后都有根因定位（py-spy 揪 singleflight 锁、死代理传 NO_PROXY、拿长度当交付判据）——这套"定位→AB→验证"的提速方法论本身就在滚动复利。

### 第三层：工具生态

工具箱 3850 件、函数索引 82,437（5 语言 30 家）、MCP 110 工具逐项真调、75 搜索入口 8 条专线——而且军团会自己补货：24 条"发现→执行→安装→自救→学习→复用"工具链矩阵（24/24），缺工具上 GitHub 自己装，装错了自己修（dogfood 抓出模型排序污染、假文件通过等四类问题并修复）。工具不是堆出来的，是带免疫系统活着的。

### 第四层：自愈与可靠性

双层自愈状态机 + DeterministicSupervisor（预算超时自动换人、不误杀正常任务）+ 跨家接力（任务+错误+文件+工作目录整体移交）+ 10 家原生/冷回放断点恢复 + 56 组已知坏组合开跑前避开。用户视角：任务很少死透，死了也能从断点爬起来。

### 第五层：进化飞轮

经验库 + 场景战绩账本 + Wilson 置信度升降级 + 坑固化成守卫测试 + 12+ 家顶尖 harness 源码当教师池 + Skill 工厂跨用户进化。本周 dogfood 自驱审计 5 轮 20 家次自己揪自己 19 个 bug（含一个凭证泄漏）——军团已经在用自己的方式变强，这是纯静态产品永远追不上的。

### 第六层：云真机（从聊天走进真实世界）

云手机跑通 F-Droid 真实全生命周期闭环（4,323 App 可信目录→SHA-256→安装→启动→卸载→快照回滚），46+24 项验证；云电脑 13 家预装脚本 + 反爬隐形浏览器栈。军团的手第一次真正伸进了 Android 和桌面软件——这是纯 API 型对手摸不到的物理世界入口。

### 第七层：验收与证据体系

321 项红黄区全绿、统一验收中心 + 发布门、终极大考 108 题（27 家互相出题 × 4 模式）、双评委独立盲评（85.8 > 84.9）、诚实账本（哪些是结构验证哪些是真跑、哪些证据还是 0%）。能自我证伪的系统才敢说自己在进步——这套证据文化让所有结论可复查、可对抗"自嗨"。

### 第八层：诚实与人机边界（信任护城河）

主动纠偏历史夸大、失败诚实返回未交付、假文件过不了关（magic bytes/SHA-256）、危险动作必须用户确认、凭证不外发（修掉 ironclaw_token 泄漏）。对用户来说，一个"说没干成就是没干成"的军团，比一个"永远说成功"的 demo 值钱得多。

**一句话总结：**别人要抄，得同时抄 21 家的真跑通、82,437 个函数索引、双层自愈、进化飞轮、云真机、108 题大考和证据文化——而且这些每周还在互相加速。护城河不是哪一项，是咬合本身。
