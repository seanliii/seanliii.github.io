### 一、Harness 全栈知识体系（面试官问什么都接得住）

#### 1. 什么是 Harness（你自己的定义，面试必答）

> Harness = 模型 + 工具 + 循环 + 记忆 + 验证的**运行装置**。模型是发动机，harness 是整车：决定 Agent 怎么用工具、怎么循环、怎么记住上下文、怎么证明自己做了。
> 我的判断：**引擎的价值在轨道不在智能**——CC 只有 1.6% 代码是 AI 决策逻辑，98.4% 是确定性基础设施。模型的差距在缩小，harness 的差距决定体验。

#### 2. Agent 循环（The Loop）的本质

- 核心公式：`Convergence Speed = Σ(Verification_Gain) / Time`（渐进式验证，对标 PID 控制器）
- "搜 1 次校验 1 次" 优于 "搜 60 次选 1 次"
- 病态模式识别：搜索成瘾（搜得多≠收敛）、早停（EARLY DONE）、假完成（部分完成说 done）
- 我的结论：**智能要长在循环里面，不是挂在循环外面**（Pilot 复盘实证）

#### 3. 上下文管理（Context）

- 三大技术：结构化事实图（我的"交接冷启动"修复）、WorldState 分段 + render_diff 增量（deepseek/dsh 系）、token 比例压缩
- 关键认知：多跳推理最大的损失不在生成，在**交接**——自然语言传递会丢 KV cache/attention/hidden state
- context not control：给 Agent 上下文而非控制，父进程不做上帝总判决

#### 4. 工具（Tools）

- Footprint Ladder（hermes）：CLI+skill → service-gated → plugin → MCP → core tool，按足迹最小接入
- 工具爆炸问题：49 个工具 vs 2 个工具的面过宽问题——工具清单如实给模型让它自己判断，不写正则枚举
- Agent 自造工具（forge）：8 步进化闭环里的 skill_synthesizer，首次 forge 省 93% token
- 万物皆插件（dsh）：插件生态是广度，工具收敛是深度

#### 5. 记忆（Memory）

- 四层架构：Session → Effective → Topic Summary → Persona
- 短中长三档 + 并行召回 + Reranker + 配额管理
- 记忆是 Agent 的地基：经验飞轮（军团）、跨 session 记忆（auto）都复用这套方法论
- 评测：LoCoMo / LongMemEval——**记忆必须可量化、可复跑、可分析**

#### 6. 验证与可靠性（Verification & Reliability）

- Verification-as-Search：校验不是终点而是另一次搜索；Critic 是检察官不是评委（每个"不同意"自带反例）
- 把"AI 会骗人"当公理设计：12 类欺骗识别、三层审计、候选交付协议（引用 evidence 必须存在于事件流）
- 评测公平性：gold 泄漏审计——**评测的第一个问题不是题目好不好，是分数是不是真的**
- 交付判据：短≠空，长度不是质量判据；Answer/Ask≤3

#### 7. 多 Agent 编排（Multi-Agent）

- 已证伪的死路（我的真数据结论）：投票、答案融合、topic 路由、一致门控——全部 ≤ 最强单家
- 唯一被证明的 1+1>1：**置信级联**（最强主家执行→读运行时信号→不满意换更强，17→21/40）
- 平台真价值：交付面扩展（设备/工具/可靠性/持久化）+ 补位接力 + 经验飞轮，不是"编排增益"
- 四臂 A/B 纪律：宣称编排更优必须过同题四臂验证（准确率/契约完成率/白卷率/墙钟/成本）

#### 8. 设备层（Device Layer）

- 云真机（Linux 桌面容器+noVNC）：Agent 操作真实桌面（终端/IDE/浏览器/拖拽）并截图取证
- 云手机（Android）：生活 App 业务状态交付（商店→安装→注册→跨 App）
- 任务状态机：needs_software→needs_account→ready→running→needs_confirmation→done 每步可断点续跑
- 意义：Agent 的边界从"文字答案"扩展到"真实设备上的业务状态"

#### 9. 模型路由与评测（Model Selection & Evals）

- 全模型自主编排（ADR-005）：删光硬编码路由，只留客观工具（list_harnesses/read_history/read_trace/run），模型 3/3 自主选对性价比最优家
- Wilson 置信度下界做模型战绩升降级
- 评测三层：公开榜（Artificial Analysis，测底座）→ 可运行题库（GAIA，测端到端）→ 盲评（Head-to-Head，测偏好），三者不可混用

### 二、通用面试题库（按出现频率排序）

#### 高频必问（15 题）

**产品判断类**

1. 你怎么定义"好 Agent"？（答：任务完成率独立判定 + Answer/Ask≤3 + 幻觉/虚假完成护栏 + 成本）
2. 如果一个 Agent 功能上线后用户反馈"它骗我"，你第一步做什么？（答：先审计交付路径而不是训模型——我的 38 道失败审计 97% 是管道）
3. 大模型能力越来越强，Agent 产品经理的价值在哪？（答：harness 的轨道价值 + 真实用户旅程的理解 + 评测体系的建设）
4. 简单问题/复杂问题你怎么路由？（答：不路由——context not control，把客观信号给模型自己选；我的 ADR-005 实证）
5. 你怎么平衡"快"和"对"？（答：首要速度指标=多久出现第一句有用内容；但交付判据不看长度看内容特征）

**技术理解类**

1. 解释一下 RAG 和 Agent 记忆的区别？（答：RAG 是检索，记忆是有结构的时间维度的状态——四层架构+衰减+冲突解决）
2. Agent loop 里最容易踩的坑？（答：早停、假完成、搜索成瘾、墙钟与门打架——我的 900s 烧到 2313s 案例）
3. 多跳推理为什么容易失败？（答：交接冷启动——自然语言传递丢隐藏状态；结构化事实图修复）
4. 评测怎么防作弊/防过拟合？（答：gold 泄漏审计四步 + 双轨评测集 + 独立集交叉验证）
5. 你怎么看 Multi-Agent 协作？（答：诚实版——证伪四方案，只有置信级联被证明；编排增益必须被证明，没证明就说没证明）

**对齐与安全类**

1. 怎么平衡安全与体验？（答：精确率比覆盖率重要，分层风险链路，误杀好用户比漏过风险样本伤害大）
2. 你怎么看"AI 会骗人"？（答：公理不是 bug——结构上无法编，而非祈祷模型别编）
3. 用户对齐怎么感知？（答：真实失败现场优先于离线指标；"把用户当老师"）

**行为面**

1. 讲一个你亲手杀死自己产品的故事？（答：Pilot——外部监控 0/10 被证伪，主动停用；智能长在循环里）
2. 讲一个你用数据推翻自己方案的故事？（答：军团证伪四方案+四臂 A/B 输了如实写进设计约束）

#### 中频题（速答卡，10 题）

| 问题 | 30 秒答法 |
| --- | --- |
| 你怎么看 GAIA 这个 benchmark？ | 可运行题库测端到端，适合做发布级验证；日常调优用业务集防过拟合 |
| 你的 Answer/Ask 指标怎么定义？ | 答案内容/提问次数，≤3 合格，>10 是把问题当项目做 |
| 什么是 context not control？ | 安全边界硬、质量策略软；并列事实不做上帝总判决 |
| 云真机解决什么问题？ | 把 Agent 交付从文字扩展到真实设备上的业务状态 |
| 经验飞轮怎么防污染？ | 采纳票（adopted）+ 按用户隔离 + 父层绝不猜用没用 |
| 补位接力为什么不丢上下文？ | 任务+错误现场+工作目录整体移交，带旧 context 不是失忆重跑 |
| 你们和 Manus 有什么区别？ | 我们更强调诚实证伪和交付判据；Manus 优势在品牌和场景深度 |
| 你最喜欢的 harness 设计？ | codex 的短循环极简 + dsh 的插件生态 + hermes 的工具足迹阶梯 |
| token 成本你怎么管？ | 配额管理、收尾预算隔离、简单题单家快答 |
| 你最大的技术短板？ | 没有大规模工程团队协作经验，独立开发者的规模化协作 |

#### 低频深水题（展示深度的机会）

- 为什么 KV cache 在交接中会丢？它对多跳推理意味着什么？
- 贝叶斯概率分布分化作为收敛判据，比覆盖率阈值好在哪？
- Wilson 置信度下界 vs 简单胜率的区别？
- 网关租约（lease）和分布式锁的区别？崩溃恢复怎么设计？
- 如果让你重写军团的调度中枢，你会改什么？（诚实答：DAG 可以更早做；派单池纯净性可以更早锁）

### 四、投递作战策略（通用）

1. **每家公司一个"钩子故事"**：投模型公司讲"评测公平性审计"，投 Agent 公司讲"交接冷启动"，投大厂讲"觅游留存"，投创业公司讲"一人 34 万行"
2. **数字背到脱口而出**：GAIA 39→61→95.2→99.4 / LoCoMo 95.1% / 幻觉 40%→2% / D0 19%→64% / 四臂 62%·6.9倍 / 769 回归 0 失败
3. **诚实三件套**：证伪四方案、Pilot 主动停用、四臂输了照写——这三个故事比任何吹牛都有杀伤力
4. **反问必问**：贵司 Agent 产品的评测体系怎么建的？/ 你们怎么定义"交付完成"？/ 团队里产品和工程怎么分工？
5. **离场动作**：24 小时内把面试记录填进第三节模板，下一场前重读
