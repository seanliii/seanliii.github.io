- **评测公平性审计**：挖出 6 个评测管道 bug（gold 答案泄漏进 trace、搜索 sandbox 挡死、旧输出污染等），对手成绩水分 31/40 → 21/40；审计自身 38 道失败发现 97% 是工程管道问题而非模型选错——「auto 不笨、不作弊，它真搜索」

### 方法论与产品哲学

- **context not control**：安全运行边界可以硬，产品质量策略必须软——不做上帝总判决，做并列事实（harness_result / runtime / peer_review / release_evidence）
- **诚实证伪优先于虚假优势**：用真数据证伪投票/融合/路由，不宣称未证明的编排优势
- **把「AI 会骗人」当公理设计，不当 bug 修**——反自欺要设计成免疫系统，从"祈祷模型别编"到"结构上无法编"
- **智能要长在循环里面，不是挂在循环外面**（Pilot 全生命周期复盘：外部监控层深度回测 0/10 被证伪，循环内部的 verify_as_search/goal_approach 反而被外部评审列为值得拿走）
- **交付判据看内容不看长度**：短≠空，长度从来不是质量判据
- **从黑盒到白盒**：Agent 不仅要做事，还要能证明自己真的做了
- **群体进化 > 单点智能**：让 Agent 读彼此源码、召回经验、补位接力，涌现智能大于各家之和
- **世界研究器模式**：先研究世界级参照，从参照反推任务与验收标准，而非凭空拍任务
